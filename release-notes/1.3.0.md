# QBittorrent.ApiClient {{VERSION}}

## Summary

Stable release for the `1.3.0` line of `QBittorrent.ApiClient`, adding support for the final qBittorrent 5.3.0 release and Web API `2.16.2`.

## qBittorrent Support

- 5.1.x
- 5.2.x
- 5.3.x

## What's New

- Added free-space queries for paths on the qBittorrent host.
- Added RSS auto-downloading rule export, import, and cloning.
- Added session pause/resume and batch operations for normal and alternative speed limits.
- Added streaming downloads of individual completed torrent files to a caller-provided stream.
- Added torrent and category share-limit modes, category share limits, and category download-path inheritance.
- Added torrent creation dotfile options and support for Unix timestamps in creation task responses.
- Added application preferences for search persistence, torrent file backups, SMTP encryption, I2P settings, session behavior, connection settings, and removal confirmations.
- Added search job details, session pause state, tracker queue and disk latency statistics, peer contribution, and optional metadata file priorities to response models.
- Added feature-specific compatibility checks to the public and internal profiles. Unsupported preference updates identify the requested properties that the server does not support.
- Added documentation covering setup, authentication, results and failures, compatibility, and common operations.
- Updated dependencies and moved the repository's tests to Microsoft.Testing.Platform with native Coverlet integration.

## Compatibility Notes

- Call `InitializeAsync()` after configuring and authenticating the client, or initialize it with the known Web API version. Version-specific request handling stays inside the library.
- Existing `ExportDir`, `ExportDirFin`, and `MailNotificationSslEnabled` updates are translated to the corresponding qBittorrent 5.3 settings. Existing `SkipChecking` options use the correct add-torrent field for the server version.
- Existing share-limit calls supply the new mode parameter when required by the server. Use the new overload to select `MatchAny` or `MatchAll` explicitly.
- Set `TorrentCategoryOptions.InheritDownloadPath` to restore the inherited download path. Leaving `DownloadPath` null preserves the existing setting when editing.
- Applications that implement `IApiClient` themselves need to implement its new members.
- The package continues to target .NET 10.

## Usage Example

After configuring and authenticating `apiClient`, initialize compatibility and read all global speed limits:

```csharp
var initializeResult = await apiClient.InitializeAsync();
if (initializeResult.IsFailure)
{
    Console.Error.WriteLine(initializeResult.Failure.UserMessage);
    return;
}

var limitsResult = await apiClient.GetSpeedLimitsAsync();
if (limitsResult.IsFailure)
{
    Console.Error.WriteLine(limitsResult.Failure.UserMessage);
    return;
}

Console.WriteLine($"Upload limit: {limitsResult.Value.UploadLimit} bytes/s");
Console.WriteLine($"Download limit: {limitsResult.Value.DownloadLimit} bytes/s");
```
