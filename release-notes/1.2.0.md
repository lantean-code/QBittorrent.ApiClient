# QBittorrent.ApiClient {{VERSION}}

## Summary

Stable release for the `1.2.0` line of `QBittorrent.ApiClient`, a standalone .NET client for the qBittorrent Web API.

## qBittorrent Support
 - 5.1.x
 - 5.2.x

## What's New

- Added a public `WebApiCompatibilityProfile` helper for consumers that need qBittorrent Web API compatibility checks outside `IApiClient`.
- Added shared internal compatibility mapping so the public compatibility profile and the internal client compatibility profile use the same version rules.
- Added `SupportsTrackerErrorFilters` compatibility detection for qBittorrent Web API `2.15.1` and later.
- Added new compatibility profile source files and dedicated tests for the new public and internal compatibility paths.
- Kept `IApiClient` unchanged and preserved internal-only compatibility details such as tracker selector encoding.

## Why It Matters

- Callers can now reuse the library's version parsing and capability mapping instead of maintaining their own compatibility helpers.
- Public compatibility checks are now available without exposing the client's cached initialization state or internal request-shaping behavior.
- Internal and public compatibility decisions now stay aligned through one shared mapping implementation.

## Usage Example

```csharp
var apiVersionResult = await apiClient.GetAPIVersionAsync();
if (!apiVersionResult.TryGetValue(out var rawApiVersion) ||
    !WebApiCompatibilityProfile.TryCreate(rawApiVersion, out var compatibilityProfile))
{
    return;
}

if (compatibilityProfile.SupportsClientData)
{
    var clientDataResult = await apiClient.LoadClientDataAsync();
}
```
