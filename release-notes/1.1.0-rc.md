# QBittorrent.ApiClient {{VERSION}}

## Summary

Stable release for the `1.1.0` line of `QBittorrent.ApiClient`, a standalone .NET client for the qBittorrent Web API.

## qBittorrent Support
 - 5.1.x
 - 5.2.x

## What's New

- Fixed compatibility profile reuse across transient `IApiClient` instances created from the same registration.
- Once one client successfully initializes compatibility metadata, later clients created for the same base address now hydrate from the shared cache automatically.
- Compatibility-gated APIs now consult the shared compatibility cache before throwing an uninitialized compatibility exception.
- Known-version registrations continue to start initialized without probing the qBittorrent instance.

## Why It Matters

- Callers no longer need to invoke `InitializeAsync()` on every transient client instance returned by `HttpClientFactory`.
- A single successful initialization per registration is now enough to unlock compatibility-gated APIs for later clients that share the same cached profile.

## Installation

```bash
dotnet add package QBittorrent.ApiClient --version {{NUGET_VERSION}}
```
